NotoColorEmoji.ttf is bundled here as a test fixture for colour font handling
(core/src/fonts). It is a bitmap-only font: it carries CBDT/CBLC colour
bitmaps and a cmap, but no glyph outlines at all. That combination is exactly
what the font-selection code must refuse — a font that looks like it covers a
character while being unable to draw anything — so the fixture is the real
thing rather than a synthetic stand-in. It is distributed under the SIL Open
Font License, Version 1.1, a permissive license that explicitly allows
